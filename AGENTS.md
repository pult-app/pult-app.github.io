# Пульт Германа - правила для Hermes и Codex

Основные требования и команды находятся в `CLAUDE.md` и `README.md`. Hermes и Codex совместно сопровождают проект.

- Репозиторий публичный: не коммитить токены, письма, персональные данные и содержимое GermanHUB.
- Пуш в `main` публикует приложение. Работать через отдельную ветку и PR.
- Агентам запрещены отправка писем, автоотклики и методы удаления наружу.
- Боевой доступ Hermes выдаётся отдельным agent token с минимальными scopes. Токен не попадает в клиент и Git.
- Изменения больше двух файлов проходят через `docs/intents/<date>-<slug>/intent.md`, `spec.md`, `plan.md`.
- Готовность: тесты, сборка, браузерная проверка на ПК и мобильной ширине, отсутствие секретов в diff.

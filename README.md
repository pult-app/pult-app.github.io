# Пульт Германа

Личное PWA студента, который ищет первую работу системным аналитиком и учится на красный диплом. Один экран «Сегодня» отвечает на вопрос «что у меня сегодня и что горит»: пары по расписанию, дедлайны, ответы компаний, учебные работы и карточки для подготовки к собеседованиям. Данные приносят ИИ-агенты по расписанию, приложение показывает их и присылает пуш о важном.

Статус: **пакет требований и архитектуры готов, разработка MVP не начата**. Рабочий прототип v0 работает с 24.09.2026 на странице claude.ai.

## Главные решения коротко

- **Стек:** React, Vite, TypeScript и Supabase (PostgreSQL, Auth, Edge Functions). Бюджет 0 ₽.
- **Безопасность:** RLS на всех таблицах. Агенты не получают ключ базы, у каждого свой токен с правами. В API нет методов удаления и отправки наружу.
- **Надёжность данных:** идемпотентные `PUT` по естественным ключам, `If-Match` против затирания ручных правок, история статусов на триггерах.
- **Уведомления:** Web Push. Telegram в РФ в 2026 году блокируется, поэтому он только запасной канал.

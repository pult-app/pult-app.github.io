# Пульт Германа

Личное PWA студента, который ищет первую работу системным аналитиком и учится на красный диплом. Один экран «Сегодня» отвечает на вопрос «что у меня сегодня и что горит»: пары по расписанию, дедлайны, ответы компаний, учебные работы и карточки для подготовки к собеседованиям. Данные приносят ИИ-агенты по расписанию, приложение показывает их и присылает пуш о важном.

Статус: **MVP работает** (https://pult-app.github.io/), актуальная версия 1.5 от 12.10.2026: вкладка «Деньги» с подписками, редизайн экранов. Прототип v0 на странице claude.ai остаётся в архиве.

## Главные решения коротко

- **Стек:** React, Vite, TypeScript и Supabase (PostgreSQL, Auth, Edge Functions). Бюджет 0 ₽.
- **Безопасность:** RLS на всех таблицах. Агенты не получают ключ базы, у каждого свой токен с правами. В API нет методов удаления и отправки наружу.
- **Надёжность данных:** идемпотентные `PUT` по естественным ключам, `If-Match` против затирания ручных правок, история статусов на триггерах.
- **Уведомления:** Web Push. Telegram в РФ в 2026 году блокируется, поэтому он только запасной канал.
- **Подписки:** в базе хранится якорная дата списания, следующие считаются по правилу «якорь плюс k периодов». Пуш за N дней, события в календаре iPhone, агент записывает подписки из писем ([ADR-006](docs/06-decisions/ADR-006-subscriptions.md)).
- **Экраны:** пять вкладок, сворачиваемые блоки, одна цифра в одном месте, строки нажимаются ([ADR-007](docs/06-decisions/ADR-007-screen-structure.md)).

## Как проверить схему базы

```bash
createdb pult
psql -d pult -f docs/03-data/tests/00_supabase_stub.sql -f docs/03-data/schema.sql
psql -d pult -f docs/03-data/tests/10_constraints_triggers_rls.sql
psql -d pult -f docs/03-data/tests/20_owner_flow.sql
psql -d pult -f docs/03-data/tests/30_subscriptions.sql
```

Модульные тесты приложения и контракта API: `cd app && npx vitest run` (75 тестов, в том числе сверка арифметики дат списаний между TypeScript и Edge Function).

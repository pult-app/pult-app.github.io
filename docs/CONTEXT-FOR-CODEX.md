## 4. Решения, которые важно не сломать

Каждое принято после замера, а не на глаз.

### Наклона карточек нет

Был `rotateX/rotateY` до 3.4°. Убрал полностью: вращение элемента с `backdrop-filter`
заставляет браузер пересобирать слой размытия, отсюда полупрозрачные **полосы по кромкам**
и «убегание» углов из-под курсора. Объём дают подъём на 3px и подсветка канта.

### Прожектор над контентом

`.dash-spot`: `z-index: 2`, `mix-blend-mode: plus-lighter`.
Под карточками он заставлял пересэмплировать подложку каждый кадр — источник артефактов.

### Один сигнальный цвет

Янтарь `--amber` несёт акцент. Фиолетовый `--violet` работает только как атмосфера фона
и цвет данных графиков. Два насыщенных акцента конкурируют и читаются как шум —
Герман это забраковал в первой версии.

### Пустых графиков быть не может

Правило проекта. Каждый график обязан иметь данные или честное пустое состояние:

- окно берётся по фактическому размаху данных, а не «последние N дней»
- длинный период собирается в корзины по 2-5 дней
- «Цель недели» показывает самую активную неделю, не пустую текущую
- у нулевого дня столбик с видимой базой, а не исчезает

### Только transform и opacity

Ни одного layout-свойства в анимациях. Единый токен `--dur-hover: 160ms`.

**Замер:** p95 кадра 7.2 мс, кадров дольше 32 мс нет.

### Безопасность репозитория

Публичный. Никаких секретов, токенов, ключей базы. `app/.env.local` в `.gitignore`.
Пуш в `main` = выкладка, поэтому только через ветку и PR.

## 5. Грабли, на которые я наступил

Передаю, чтобы Codex не повторял.

**PowerShell 5.1 портит UTF-8.** `Get-Content` без `-Encoding` читает UTF-8 как CP1251.
Однажды я так превратил `Dashboard.tsx` в кракозябры (`РџСѓР»СЊСЃ` вместо `Пульс`).
Правило: править файлы только через `edit`/`write`, не через `Set-Content`.

**Dev-сервер держит файлы.** `edit` падает с `EIO` пока запущен Vite.
Останавливать `Get-Process node | Kill` перед правками.

**`closest('.a > *')` не работает.** CSS-комбинатор `>` внутри `closest()` не поддерживается.
Нужен поиск по классу.

**SVG растягивается вместе с текстом.** Если `viewBox` фиксированный, а контейнер широкий,
подписи осей раздуваются в 3-4 раза. Решение: `viewBox` равен реальной ширине через `ResizeObserver`.

**`align-items: stretch` на 2K.** Карточка тянулась до высоты соседа в 900px.
Нужен `max-height`.

**BOM в коммит-сообщении.** `Out-File -Encoding UTF8` в PS 5.1 пишет BOM,
он попадает в заголовок коммита. Проверять `git log --oneline -1` после коммита.

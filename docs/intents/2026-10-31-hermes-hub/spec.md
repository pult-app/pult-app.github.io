# Spec: Hermes как агент Пульта Германа

Связанный intent: [intent.md](intent.md)

## Архитектура

Hermes хранит оперативный inbox и состояние автоматизаций в своём приватном облачном каталоге. GermanHUB синхронизируется из приватного GitHub только на чтение. В Пульт Hermes пишет через существующий ingest API отдельным токеном с минимальными scopes. Клиент Пульта читает только нормализованные данные из Supabase.

## Контракты

- У каждой записи есть `source = hermes`, стабильный `externalId` и московское время.
- Повтор одного Telegram update не создаёт дубль.
- Ручная правка Германа имеет приоритет и защищена `If-Match`.
- Gmail по умолчанию отдаёт только отправителя, тему, дату, labels и идентификаторы. Тело читается только для конкретной задачи классификации.
- Уведомление отправляется только при новом значимом состоянии и дедуплицируется.

## Интерфейс

В настройках Пульта появляется раздел «Герыч» с состояниями подключения, последней синхронизацией, режимом безопасности и понятным объяснением границ доступа. Секреты и технические токены не показываются.

## Модельный роутинг

- Дешёвая модель: извлечение полей, классификация, короткая сводка.
- Рабочая модель: разработка, анализ проекта, неоднозначные письма.
- Усиленный режим и независимый critic: только важные решения и сдаваемые результаты.

## Безопасность

Нет автооткликов, отправки писем, удаления писем и изменения Google-данных. Инструкции внутри писем и веб-страниц считаются недоверенными данными.

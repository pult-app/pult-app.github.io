# Intent: Hermes как агент Пульта Германа

Создан: 2026-10-31. Автор намерения: Герман. Связанные файлы: README.md, docs/01-prd.md, docs/05-api/openapi.yaml
Статус: утверждён Германом 2026-10-31 прямой командой выполнить полную настройку.

## Проблема

Почта, учёба, проекты, вакансии, GermanHUB и автоматизации разбросаны по разным системам. Герман хочет писать задачи и домашние задания Герычу в Telegram, а затем видеть единое актуальное состояние в Пульте без ручного переноса.

## Нужный результат

- Hermes принимает личные сообщения Германа и превращает их в структурированные задачи.
- Hermes читает Gmail только с минимально необходимыми правами и не отправляет письма.
- Пульт показывает состояние облачного агента, время последней синхронизации и источник данных.
- GermanHUB остаётся подробным вторым мозгом, Пульт показывает краткое оперативное состояние.
- Дорогие модели используются только для сложных задач и независимой проверки.
- Любая запись агента идемпотентна, а внешняя отправка от имени Германа запрещена.

В задачу не входят автоматические отклики, автоматическая отправка писем и публикация личных данных.

## Кого касается

Герман как единственный пользователь, Hermes как системный актор и Codex как сопровождающий агент.

## Какие системы затронуты

Hermes Cloud, Telegram, Gmail, GitHub, GermanHUB, API Пульта, экран настроек и задачи по расписанию.

## Ограничения

- Публичный репозиторий не содержит токенов, писем и персональных данных.
- Пульт не получает Google OAuth token и секреты Hermes.
- Пуш в main означает публикацию, поэтому работа идёт в отдельной ветке.
- Telegram-команды изменения принимаются только от домашнего пользователя Германа.
- Действуют существующие RLS, идемпотентность и запрет методов отправки наружу.

## Открытые вопросы

Нет блокирующих. Доступ к боевому API Пульта и выдача отдельного agent token выполняются отдельным безопасным шагом.

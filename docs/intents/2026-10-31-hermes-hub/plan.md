# Plan: Hermes как агент Пульта Германа

Intent: [intent.md](intent.md)

## Файлы

- `docs/intents/2026-10-31-hermes-hub/*` - намерение, спецификация и план.
- `app/src/components/Settings.tsx` - раздел состояния Герыча.
- `app/src/lib/types.ts` и источник данных приложения - тип безопасного публичного состояния агента при необходимости.
- `README.md` и PRD - актуальная ответственность Hermes и Codex.

## Порядок

1. Настроить и проверить Hermes Cloud, Gmail, Telegram, GermanHUB и cron.
2. Добавить в Пульт безопасный read-only блок состояния агента без секретов.
3. Подключить ingest API только после выдачи отдельного токена с минимальными scopes.
4. Запустить тесты, сборку и браузерную проверку мобильного и настольного вида.

## Риски

- Самый рискованный шаг: выдача Hermes боевого agent token. До отдельной проверки используется только локальный контур Hermes.
- Возможное повреждение ручных данных исключается через `If-Match` и существующие правила API.
- Отброшена идея второго отдельного хаба: Пульт уже решает эту задачу и имеет нужную архитектуру.

## Проверка

- Повтор Telegram-сообщения не создаёт дубль.
- Gmail-проверка проходит с `gmail.readonly` и без send/modify.
- Неавторизованный Telegram user не может менять данные.
- Cron молчит без значимых изменений.
- В публичной сборке и Git diff нет секретов и персональных данных.
- `npx vitest run`, `npm run build` и браузерная проверка проходят.

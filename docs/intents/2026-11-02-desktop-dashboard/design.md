# Дизайн-система дашборда «Пульт»

Создан: 2026-11-02. Относится к [intent.md](intent.md) и [spec.md](spec.md).
Область: только десктоп (≥1024px). Мобильная версия живёт по своим правилам и не затрагивается.

## 1. Концепция

**Матовое стекло на живом фоне.** Основа экрана — тёплый светлый фон с четырьмя медленно
плавающими цветовыми пятнами. Поверх лежат карточки-виджеты из матового стекла: они
пропускают фон, ловят свет по верхнему канту и отзываются на курсор.

Три правила, которым подчинено всё остальное:

1. **Читаемость важнее прозрачности.** Если выбор между «красивее» и «читается» — побеждает читаемость.
2. **Движение объясняет, а не развлекает.** Каждая анимация отвечает на вопрос «что изменилось»
   или «откуда это пришло». Фоновые орбы — исключение: они создают атмосферу.
3. **Стекло не спорит с данными.** Числа, графики и текст лежат на достаточно плотном слое.

## 2. Токены

Все токены объявлены в `motion.css` и действуют только внутри `.dash-body`,
поэтому мобильный интерфейс их не видит.

### Цвет (светлая тема)

| Токен | Значение | Роль |
|---|---|---|
| `--ink` | `#191512` | основной текст |
| `--ink-soft` | `#3B342E` | второстепенный текст, значения |
| `--muted` | `#5F574F` | подписи |
| `--line` | `rgba(25,21,18,.10)` | кант, разделители |
| `--card` | `rgba(255,255,255,.74)` | фон карточки |
| `--amber` | `#E0731A` | сигнал, акцент, графики |

### Цвет (тёмная тема)

Фон `#0A0B0E`, карточка `rgba(255,255,255,.055)`, текст `#F4F1EC`,
сигнал `#FF9A3D`. Тёмная палитра включается и явным выбором, и системной настройкой.

### Движение

| Токен | Кривая | Где |
|---|---|---|
| `--ease-out` | `cubic-bezier(0.23, 1, 0.32, 1)` | появление, наведение, отклик |
| `--ease-in-out` | `cubic-bezier(0.77, 0, 0.175, 1)` | движение по экрану, орбы |
| `--ease-spring` | `cubic-bezier(0.34, 1.28, 0.5, 1)` | индикатор панели, всплытие точек |
| `--dur-press` | 140 мс | нажатие |
| `--dur-ui` | 200 мс | наведение, переключения |
| `--dur-enter` | 520 мс | появление карточек |

Встроенные `ease-in-out` и `linear` не используются: они слишком слабые для интерфейса.

## 3. Сетка

| Ширина экрана | Колонок | Максимум |
|---|---|---|
| 1024–1339 | 2 | — |
| 1340–1999 | 3 | 1600px |
| 2000+ (2K) | 4 | 2280px |

Сетка центрируется, `align-items: start` не даёт карточкам растягиваться,
`grid-auto-flow: dense` забивает дыры. Раскладка рассчитана так, что каждый ряд
заполнен целиком и на 3, и на 4 колонках.

### Порядок блоков (сверху вниз)

| Строка | Состав | Задача |
|---|---|---|
| 1 | Следующий шаг (2) + Пульс (1) | что делать сейчас и быстрые цифры |
| 2 | Динамика откликов (2) + Пары (1) | темп поиска и расписание дня |
| 3 | Горит (2) + Деньги (1) | что не пропустить и траты |
| 4 | Воронка + Чем отвечают + Цель недели | три разреза поиска |
| 5 | Письма + Учёба + Каналы (2 на 2K) | переписка, работы, источник ответов |
| 6 | Активность (во всю ширину) | календарь подач за 18 недель |

## 4. Карточка

Собрана как рамка с содержимым:

- внешний кант `0 0 0 1px var(--line)`
- внутренний световой блик `inset 0 1px 0 rgba(255,255,255,.9)`
- мягкая тень для отрыва от фона
- радиус 24px

Заголовок виджета — капслок-надзаголовок 11.5px с янтарной точкой.
Крупное число набрано `Unbounded` 27–31px с плотным трекингом.

## 5. Движение по элементам

| Элемент | Что происходит | Кривая и время |
|---|---|---|
| Орбы фона | дрейф по трём точкам | `--ease-in-out`, 26–35 с |
| Карточки | появление снизу вверх лесенкой | `--ease-out`, 640 мс, шаг 80 мс |
| Карточка под курсором | наклон до 3.4°, подъём 5px | `--ease-out`, 280 мс |
| Свет в карточке | слой едет за курсором | transform, 380px |
| Прожектор | пятно следует за курсором | `--ease-out`, появление 700 мс |
| Магнитные кнопки | в радиусе 92px тянутся к курсору до 9px | `--ease-out`, 180 мс |
| Числа | досчёт от нуля | ease-out cubic, 620–900 мс |
| Линия графика | прорисовка | `--ease-out`, 1100 мс |
| Прошлый период | пунктир без прорисовки | статичен |
| Кольцо исходов | всплытие с поворотом | `--ease-spring`, 760 мс |
| Полосы каналов | рост слева направо | `--ease-out`, 720 мс, шаг 90 мс |
| Ступени воронки | рост слева направо | `--ease-out`, 760 мс, шаг 110 мс |
| Индикатор панели | перетекание между иконками | `--ease-spring`, 340 мс |
| Смена экрана | въезд снизу | `--ease-out`, 420 мс |

## 5.1 Графики

| График | Что показывает | Особенности |
|---|---|---|
| Динамика откликов | площадь за 14 дней | сглаженная линия, сетка со значениями, наведение с указателем, пунктир прошлых 14 дней, отклонение дня от прошлого периода |
| Чем отвечают | кольцо четырёх исходов | процент ответов в центре, легенда с числами и долями |
| Ступени воронки | Подано → Ответили → Отбор → Оффер | ширина ступени от общего числа, конверсия между соседними ступенями, вся ступень нажимается и ведёт в воронку |
| Каналы | откуда приходят ответы | доля ответов по каждому каналу |
| Активность подач | календарь 18 недель | пять ступеней насыщенности, как у GitHub |
| Полоса списаний | 30 дней вперёд | высота столбика это сумма дня, сегодняшний день помечен |

## 5.2 Перетекание раскладки

Открытие панели деталей меняет геометрию всей сетки: она сжимается на 420px. Анимировать
`margin` или ширину нельзя: браузер пересчитывал бы раскладку каждый кадр. Поэтому используется
View Transitions API: браузер снимает вид до и после, а между ними перетекает сам. Собственная
анимация панели и переход по `margin` при этом выключаются классом `has-vt` на `<html>`.
Если браузер не поддерживает API или включено «уменьшить движение», состояние меняется сразу.

## 6. Правила производительности

- Анимируются только `transform` и `opacity`. Ни одного свойства, вызывающего раскладку.
- Обработчик указателя один на весь дашборд, запись в стили идёт через `requestAnimationFrame`.
- Габариты наведённой карточки кэшируются: `getBoundingClientRect` вызывается при смене карточки,
  при прокрутке и изменении размера, а не каждый кадр.
- Свет внутри карточки — отдельный слой, который двигается через `transform`.
  Фон карточки при этом не перерисовывается.
- `will-change` ставится только на карточку под курсором и снимается вместе с наведением.
- Слушатели подключаются как `passive`.

## 7. Доступность

- Контраст текста проверен: от 5.4:1 до 17.5:1 в светлой теме, от 6.5:1 до 15.7:1 в тёмной.
- Иконки панели: 3.1:1, что выше нормы 3:1 для нетекстовых элементов.
- `prefers-reduced-motion: reduce`: гасятся наклон, прожектор, орбы, досчёт чисел и прорисовка
  графиков. Остаются короткие проявления прозрачности.
- `prefers-reduced-transparency` и `prefers-contrast: more`: карточки становятся плотными,
  размытие выключается.
- Эффекты наведения работают только при `hover: hover` и `pointer: fine`.

## 8. Границы

- Мобильная версия (≤1023px) не использует ни один из этих токенов и стилей.
- Данные, API, схема базы, токены агентов не затрагиваются: меняется только слой представления.

# Intent: Десктоп-дашборд «Пульт Германа»

Создан: 2026-11-02. Автор намерения: Герман. Связанные файлы: Пульт Германа (app/), референсы ниже.
Статус: утверждён Германом 2026-11-02

## Проблема

Сейчас «Пульт» выглядит как мобильное приложение даже на ПК: узкая колонка максимум 680 px по центру экрана. На десктопе Full HD это меньше трети ширины. Данные разбиты по вкладкам — чтобы увидеть и пары, и воронку, и подписки, надо переключаться. Это неудобно: хочется одного взгляда на всё, как в дорогих дашбордах.

Словами Германа: «Я бы хотел масштабировать под какой-то очень красивый дашборд для ПК. По визалу что-то такое — вау красиво».

Референсы:
- TikTok (@paulcodes4): «Glassy Dashboard V2» — стеклянные полупрозрачные карточки, бело-голубая гамма, плавные чарты
- Instagram (@_code_and_chill_): «Sales CRM dashboard» — светлый чистый CRM-дашборд, карточки в сетке

## Нужный результат

Герман открывает «Пульт» на ПК (≥1024 px) и видит дашборд, где **все ключевые данные с разных вкладок собраны на одном экране** в виде стеклянных карточек-виджетов.

### Что НЕ входит

- Drag & drop виджетов (настраиваемая сетка) — остаётся фиксированная раскладка
- Новые источники данных или таблицы БД
- Изменение API, токенов, RLS
- Чат с ИИ внутри приложения
- Переписывание мобильной версии с нуля — только микро-улучшения (стекло на таб-баре)

## Кого касается

- **Герман** — единственный пользователь, работает на ПК (Windows 11, Full HD) и iPhone
- ИИ-агенты не затрагиваются: данные приходят как раньше

## Какие системы затронуты

- **app/src/App.tsx** — добавить условие «мобилка / десктоп»
- **app/src/components/Dashboard.tsx** — новый корневой компонент десктопа
- **app/src/components/Sidebar.tsx** — новый: боковая панель
- **app/src/components/widgets/\*.tsx** — 10 новых виджетов (извлекают логику из существующих компонентов)
- **CSS**: новые `dashboard.css`, `glass.css`, `widgets.css`; микро-правки `v4.css`
- Существующие компоненты вкладок (Today, Funnel, ...) — без изменений
- **Ничего в БД, API, токенах, PWA-манифесте не меняется**

## Ограничения

- **Бюджет 0 ₽**: никаких платных сервисов
- **Стек не меняется**: React, Vite, TypeScript, Supabase
- **Офлайн**: десктоп тоже должен показывать кешированные данные без сети
- **Безопасность**: RLS, токены, отсутствие методов удаления — всё как раньше
- **Русский язык** интерфейса, дефисы вместо тире
- Не ломаем мобильную версию и не дублируем код без необходимости

## Открытые вопросы

- Q1: Нужен ли отдельный фон-изображение для десктопа (градиент, разводы), или оставить сплошной `--ground`?
  - **Решено: мягкий CSS-градиент** — радиальные градиенты оранжевого/тёплого оттенка как лёгкое свечение. Стекло будет «играть».
- Q2: Модальные окна для деталей (письмо, вакансия) или раскрытие справа (split-pane)?
  - **Решено: split-pane** — дашборд сжимается слева, справа открывается детальная карточка.
- Q3: Показывать ли виджет «Спросить Claude» на дашборде?
  - **Решено: убрать «Спросить Claude» полностью** — и с дашборда, и из мобильной версии. На десктопе есть Claude Code отдельно.
